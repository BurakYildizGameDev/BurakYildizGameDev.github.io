Reporting a bug

These help me reproduce the problem on the first try:

  • The package and its version (shown in Window → Package Manager).
  • Your Unity version and render pipeline.
  • What you did, what you expected and what happened instead.
  • The Console output, and if possible Editor.log (Console → ⋮ → Open Editor Log).
  • Screenshots, or a small project that shows the problem.

Please include your invoice number from the Asset Store order for Pro features.

FAQ

Does Project Doctor delete my files?

No. Cleanup moves files to ProjectDoctorQuarantine/ next to your Assets/ folder, together with their .meta files, so GUIDs survive. Quarantine → Restore Session brings them back. Delete Permanently… is the only irreversible action, and it asks first.

Which Unity versions are supported?

Unity {{pdUnity}}. It is tested on 2022.3.62f3 and 6000.5.0f1.

Does it work with URP or HDRP?

Yes. Project Doctor never touches rendering, so any render pipeline works. The Pro audit flags materials that would render pink in your project's pipeline.

Does anything end up in my player build?

No. It is an editor-only assembly with no runtime footprint.

Why is an asset marked "Medium" instead of "High"?

Medium means the asset may still be used without a serialized reference, for example loaded by name from code, so it is listed under To review and never bulk-selected. High findings are safe to bulk-move.

I have the free version installed. Can I add Pro?

Yes. Pro detects the free package and asks you to remove it, because both carry the same classes.

How do refunds work?

Purchases and refunds go through the Unity Asset Store and follow its terms. If something doesn't work for you, please write first: most problems can be fixed quickly.
