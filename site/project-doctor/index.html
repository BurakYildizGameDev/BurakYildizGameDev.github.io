Three questions, answered

Unity projects collect dead weight: textures from abandoned prototypes, materials nobody assigns, prefabs whose scripts were deleted. Deleting by hand is risky, because Unity can load assets in ways a quick search doesn't show.

What can my build really reach?

A dependency graph from the real build roots: Build Settings scenes, Resources, Addressables, AssetBundles, Project Settings and packages. Everything else is a cleanup candidate, sorted by size.

What is broken?

Missing scripts, broken object references, orphaned prefab instances and event calls to renamed methods, located down to the GameObject, component and field.

How do I clean up safely?

Nothing is deleted. Files move to a quarantine with their .meta, so GUIDs survive and references reconnect after a restore.

Features

  • Two confidence levels. High findings are safe to bulk-move. Medium findings may still be used without a serialized reference, so they are never bulk-selected.
  • Missing references in prefabs, scenes and native assets: materials, ScriptableObjects, animator controllers, timelines.
  • One-click missing-script removal in prefabs (variants and nested prefabs included) and scenes, open or closed.
  • References browser: what an asset uses and what uses it, right from the Project window context menu.
  • Health score (0–100) that writes out its own calculation and the points each quick win can win back.
  • Version control aware: with a provider such as Perforce active, files are checked out before they move.
  • Fast: about 6 seconds for 11,000 assets and about a minute for 100,000, without freezing the Editor. Rescans reuse what didn't change.

Quick start

  1. Import the package from Window → Package Manager → My Assets.
  2. Open Tools → Project Doctor and press Scan Project. The Editor stays responsive; you can cancel at any time.
  3. Read the Overview: the health score, why it is what it is, and the quick wins.
  4. Open Unused, keep the confidence filter on High, check what you don't need and press Move to Quarantine…
  5. Open Missing and double-click a row to jump to the broken GameObject.
  6. Changed your mind? Quarantine → Restore Session puts everything back.

Tip: add /ProjectDoctorQuarantine/ to your .gitignore so quarantined files never end up in a commit. Project Doctor offers to do this after your first quarantine.
